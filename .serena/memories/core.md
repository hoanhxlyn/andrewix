# andrewix — NixOS config

Personal NixOS + Home Manager flake for 5 hosts (asus-rog-gl552vx, msi-gf63, home-pc, home-wsl, work-wsl).
User: andrew, system x86_64-linux. The React SPA in `web/` is separate from the Nix config — see `mem:web/core`.

## Source map

- flake.nix — AUTO-GENERATED by nix run .#write-flake. NEVER edit by hand; regenerate after adding inputs or editing flake-file.*.
- modules/hosts.nix — one mkHost entry per host: hardware facts (chassis, cpu, gpu, bootLoader, storage, chargeThreshold, enableGaming) + monitors. ONLY place hostnames appear.
- modules/schema.nix + modules/_lib/host-facts.nix — fact types feed den.schema.host; mkHost rejects unknown fact names.
- modules/_lib/mk-host.nix — host builder: composes _settings.nix + per-host data + variant. These 3 files (hosts.nix, schema.nix, _lib/mk-host.nix) use relative imports because flake outputs compute; every other file takes {self, ...} and imports via ${self} (relative imports elsewhere are a bug).
- modules/core/ — aspects under namespace core.<name>, one dir per domain: agents, browsers, desktop, editor, gaming, gui, hardware, locale, media, office, services, shell, system, terminals.
- modules/devices/{workstation,homelab,wsl}.nix — variant aspects, included by variant, never by hostname.
- modules/defaults.nix, modules/dendritic.nix — default includes + framework bootstrap.
- secrets/ — sops-nix; declare secrets in modules/core/services/sync/sops.nix; edit via sops secrets/secrets.yaml.
- config/<tool>/ — raw app configs, symlinked via home.file."<dest>".source = "${self}/config/<tool>/<file>".
- _<name>/ dirs (_nvf, _nwm, _lib) — NOT aspects, not auto-discovered; path-imported from their parent aspect.
- scripts/ — fish helpers behind Justfile recipes (update, search, schemes, rollback, homelab) + attr-style (Rust CLI implementing the dotted-path rule).
- install.fish — installer: prompts for the first-boot password and sets it via nixos-enter before reboot.
- .github/ — issue templates only, no CI.

## Invariants

- Dendritic composition: den.aspects.<name>.includes with angle-bracket imports (<core/sound>). Never imports.
- New .nix files must be git added BEFORE build (flakes see tracked files only) — untracked aspect gives: Namespace 'core' has no aspect 'new-aspect'.
- stateVersion 26.05 in modules/core/system/nix-setting.nix (system + HM). NEVER change.
- No system python/python3. Run python only via uv (uv run python ...).
- uv tool installs need `--python '>=3.11,<3.15'` (home.activation.uvTools; why: `mem:tech_stack`).
- Tools come from Nix (modules/core/), no pre-commit hooks.
- No unit tests for the Nix config — validation = just build + just test.
- WSL hosts not installable (no disk layout).
- Gradient NAR store lives on the homelab HDD /data/gradient (label gradient, needs hand-rolled mkfs.xfs on fresh disks).
