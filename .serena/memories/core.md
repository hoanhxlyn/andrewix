# andrewix — NixOS config

Personal NixOS + Home Manager flake for 5 hosts (asus-rog-gl552vx, msi-gf63, home-pc, home-wsl, work-wsl).
User: andrew, system x86_64-linux.

## Source map

- flake.nix — AUTO-GENERATED by nix run .#write-flake. NEVER edit by hand. NEVER nix flake update without regenerating after flake-file edits.
- modules/hosts.nix — mkHost per host: hardware facts (chassis, cpu, gpu, bootLoader, storage, chargeThreshold, enableGaming) + monitors. ONLY place hostnames appear.
- modules/schema.nix + modules/_lib/host-facts.nix — fact types feed den.schema.host; mkHost rejects unknown facts.
- modules/_lib/mk-host.nix — host builder: composes _settings.nix + per-host data + variant. These 3 files (hosts.nix, schema.nix, _lib/mk-host.nix) use relative imports because flake outputs compute; all other files take {self, ...} and import via ${self} (relative imports elsewhere are a bug).
- modules/core/ — aspects, namespace core.<name>, each aspect = {nixos, homeManager, includes}.
- modules/devices/{workstation,homelab,wsl}.nix — variant aspects, included by variant, never by hostname.
- modules/defaults.nix, modules/dendritic.nix — default includes + framework bootstrap.
- secrets/ — sops-nix; declare secrets in modules/core/services/sync/sops.nix; edit via sops secrets/secrets.yaml.
- config/<tool>/ — non-Nix app configs, symlinked via home.file."<dest>".source = "${self}/config/<tool>/<file>".
- _<name>/ dirs (_nvf, _nwm, _lib) — NOT aspects, not auto-discovered; path-imported from their parent aspect.

## Invariants

- Dendritic composition: den.aspects.<name>.includes with angle-bracket imports (<core/sound>). Never imports.
- New files must be git added BEFORE build (flakes see tracked files only) — untracked aspect gives: Namespace 'core' has no aspect 'new-aspect'.
- stateVersion 26.05, set once in modules/core/system/nix-setting.nix. NEVER change.
- No system python/python3. Run python only via uv (uv run python ...).
- Tools come from Nix (modules/core/), no pre-commit hooks.
- No unit tests — validation = just build + just test.
- WSL hosts not installable (no disk layout).
- Gradient NAR store lives on homelab HDD /data/gradient (label gradient, needs hand-rolled mkfs.xfs on fresh disks).
